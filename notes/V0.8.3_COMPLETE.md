## 📝 User Guide

### Viewing OWASP Top 10 Coverage

1. Navigate to project dashboard
2. Locate "OWASP Top 10 Coverage" widget (row 2)
3. View coverage percentage (red = high, green = low)
4. See top 5 categories with progress bars
5. Check summary statistics

**Interpretation**:
- **High Coverage (70%+)**: Many vulnerabilities match OWASP Top 10 ⚠️
- **Medium Coverage (30-70%)**: Some critical vulnerabilities 🟡
- **Low Coverage (0-30%)**: Few OWASP Top 10 issues ✅

### Viewing CWE Top 25 Coverage

1. Navigate to project dashboard
2. Locate "CWE Top 25 Coverage" widget (row 2)
3. View coverage percentage
4. See top 5 weaknesses ranked by finding count
5. Check severity badges (Critical/High/Medium/Low)

**Severity Colors**:
- 🔴 **Critical**: Red (#d32f2f)
- 🟠 **High**: Orange (#f57c00)
- 🟡 **Medium**: Yellow (#fbc02d)
- 🟢 **Low**: Green (#388e3c)

### Understanding Auto-Detection

When you upload a report or create a finding:

1. **CWE Extraction**: Scans title/description for CWE-XXX patterns
2. **Type Matching**: Checks vulnerability type (e.g., "SQL Injection" → CWE-89)
3. **OWASP Mapping**: Maps CWE to OWASP category (CWE-89 → A03)
4. **Storage**: Saves `owasp_category` in database

## 🐛 Known Issues & Limitations

### Current Limitations

1. **Compliance Reports**: Deferred to future release
   - Planned: DOCX/PDF reports with full compliance breakdown
   - Workaround: Use dashboard widgets + manual screenshots

2. **Manual CWE Override**: Not yet implemented
   - Auto-detection is ~90% accurate
   - Planned: Allow users to manually set CWE for edge cases

3. **Historical Data**: Existing findings need re-processing
   - New findings get auto-detection
   - Old findings need manual update or re-upload

4. **"View Full Report" Buttons**: Disabled (future feature)
   - Buttons present but non-functional
   - Planned: Dedicated compliance pages

### Workarounds

**For Old Findings**:
```bash
# Re-upload reports to trigger auto-detection
# OR update via SQL:
UPDATE finding 
SET owasp_category = 'A03' 
WHERE title LIKE '%SQL%' AND project_id = 1;
```

**For Missing CWE**:
- Include "CWE-XXX" in finding title or description
- Auto-detection will extract and map

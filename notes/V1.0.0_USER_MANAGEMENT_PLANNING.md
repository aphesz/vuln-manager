## Phase 1: Backend - User Model & Authentication (Priority)

### 1.1 Database Schema
**New Tables:**

```python
# User model
class User(SQLModel, table=True):
    id: Optional[int] = Field(default=None, primary_key=True)
    email: str = Field(unique=True, index=True)
    username: str = Field(unique=True, index=True)
    hashed_password: str
    full_name: Optional[str] = None
    role: str = Field(default="viewer")  # admin, analyst, viewer
    is_active: bool = Field(default=True)
    is_superuser: bool = Field(default=False)
    created_at: datetime = Field(default_factory=datetime.utcnow)
    last_login: Optional[datetime] = None
    avatar_url: Optional[str] = None
```

**Roles:**
- `admin` - Full access (CRUD all resources, user management)
- `analyst` - Read/Write projects, findings, reports (no user management)
- `viewer` - Read-only access

### 1.2 Authentication System
**Technology:**
- JWT tokens (access + refresh)
- Password hashing with `passlib` + `bcrypt`
- OAuth2 password bearer flow

**Endpoints:**
```
POST   /auth/register          - Register new user
POST   /auth/login            - Login (returns JWT tokens)
POST   /auth/refresh          - Refresh access token
POST   /auth/logout           - Logout (invalidate token)
GET    /auth/me               - Get current user profile
PUT    /auth/me               - Update current user profile
PUT    /auth/me/password      - Change password
```

### 1.3 Authorization Middleware
**Dependencies:**
```python
def get_current_user(token: str = Depends(oauth2_scheme)) -> User
def get_current_active_user(current_user: User = Depends(get_current_user)) -> User
def require_role(role: str) -> User  # Role-based dependency
```

**Protected Endpoints:**
- All `/projects/*` - Require authenticated user
- All `/findings/*` - Require authenticated user
- `DELETE /projects/*` - Require analyst or admin
- `POST /users/*` - Require admin only

## Security Considerations

### Password Requirements
- Minimum 8 characters
- At least 1 uppercase, 1 lowercase, 1 number
- Optional: Special character requirement

### Token Security
- Access token: 15-30 minutes expiry
- Refresh token: 7 days expiry
- Tokens stored securely (httpOnly cookies for refresh)

### API Security
- Rate limiting on auth endpoints (5 attempts/minute)
- CSRF protection
- CORS configuration
- SQL injection prevention (parameterized queries)

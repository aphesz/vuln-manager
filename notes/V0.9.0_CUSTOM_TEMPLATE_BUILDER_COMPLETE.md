### 📝 Template Structure (20% of work)

**JSON Schema**
```json
{
  "sections": [
    {
      "type": "text|metrics|chart|findings|table",
      "title": "Section Title",
      "content": "...",              // for text sections
      "widgets": ["..."],            // for metrics sections
      "chart_type": "...",           // for chart sections
      "filters": {                   // for findings sections
        "risk_rating": ["Critical", "High"]
      }
    }
  ],
  "layout": {
    "page_size": "letter|a4",
    "orientation": "portrait|landscape",
    "margins": {
      "top": 40,
      "bottom": 40,
      "left": 40,
      "right": 40
    }
  }
}
```

**Section Types**
1. **text**: Raw content blocks with HTML support
2. **metrics**: KPI widgets (total findings, risk distribution, remediation rate, SLA compliance)
3. **chart**: Visualizations (risk over time, findings timeline, remediation progress, attack surface)
4. **findings**: Filtered findings tables with risk rating filters
5. **table**: Generic data tables

**Widget Types**
- `key_metrics`: Total findings count
- `risk_distribution`: Breakdown by Critical/High/Medium/Low
- `remediation_rate`: Percentage of closed findings
- `sla_compliance`: SLA adherence metrics

**Chart Types**
- `risk_over_time`: Time-series risk trends
- `findings_timeline`: Findings discovered over time
- `remediation_progress`: Closure rate progress
- `attack_surface`: Attack surface visualization

## User Workflows

### Creating a Custom Template
1. Navigate to "Templates" in header
2. Click "Create New Template"
3. Fill in template name and description
4. Configure page layout (size, orientation, margins)
5. Add sections:
   - Click "Add Section"
   - Choose section type
   - Configure type-specific settings
   - Reorder with up/down arrows
6. Click "Save Template"
7. Redirected to edit mode for further refinement

### Managing Templates
1. Open Template Library (`/custom-templates`)
2. Search by name/description
3. View template cards with metadata
4. Actions:
   - **View**: See full details
   - **Edit**: Modify template
   - **Duplicate**: Clone for variations
   - **Delete**: Remove with confirmation

### Generating Reports
1. Go to Reports page
2. Select "Custom Template" as template type
3. Choose saved template from dropdown
4. Select format (HTML/DOCX/PDF)
5. Filter by projects, date range
6. Click "Generate"
7. Download generated report

## Lessons Learned

1. **Session Management**: Always extract ORM object properties before closing database session to avoid DetachedInstanceError
2. **Enum Values**: FastAPI enums are case-sensitive; use exact string values in API requests
3. **Rate Limiting**: Apply different limits based on operation cost (30/min for writes, 60/min for reads)
4. **JSON Validation**: Validate on both client and server; TypeScript interfaces don't guarantee runtime structure
5. **Docker Volumes**: Use `docker cp` for immediate file updates; volume mounts may cache
6. **Error Feedback**: Return clear, actionable error messages (e.g., "custom_template_id is required for Custom template type")
7. **Usage Tracking**: Simple counters can provide valuable analytics with minimal overhead
8. **Component Size**: 500+ line components are OK if they're self-contained and cohesive (see CustomTemplateBuilder)

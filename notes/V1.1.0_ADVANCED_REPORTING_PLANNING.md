## 🛠️ Technical Decisions

### Report Generation Library
**Choice:** Use existing `reportlab` for PDF, add `matplotlib` for charts

**Alternatives Considered:**
- WeasyPrint (HTML to PDF) - Good for complex layouts
- LaTeX (via pdflatex) - Best quality but complex setup
- Puppeteer/Playwright (headless browser) - Overkill for simple reports

**Rationale:** `reportlab` already in use, lightweight, no external dependencies.

### Chart Generation
**Choice:** `matplotlib` for static charts embedded in PDFs

**Alternatives:**
- Plotly - Interactive but requires JavaScript runtime
- Chart.js - Frontend-only, can't embed in PDF
- Seaborn - Better aesthetics but heavier

**Rationale:** Matplotlib integrates easily with reportlab, widely supported.

### Scheduled Jobs
**Choice:** APScheduler (in-process scheduler)

**Alternatives:**
- Celery Beat - Requires Redis/RabbitMQ broker
- Cron + Management Command - Less flexible

**Rationale:** APScheduler is lightweight, no external dependencies for MVP.

### Email Service
**Choice:** Start with SMTP (configurable), recommend SendGrid

**Alternatives:**
- AWS SES - Good for AWS-hosted deployments
- Mailgun - Simple API
- Postmark - Transactional focus

**Rationale:** SMTP is universal, users can bring their own provider.

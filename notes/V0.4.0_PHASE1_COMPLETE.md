## 🗄️ Database Schema

### vulnerability_templates
```sql
CREATE TABLE vulnerability_templates (
    id SERIAL PRIMARY KEY,
    title VARCHAR(500) NOT NULL,
    description TEXT NOT NULL,
    cwe_id VARCHAR(20),
    cve_id VARCHAR(50),
    cvss_vector VARCHAR(100),
    cvss_score FLOAT CHECK (cvss_score >= 0.0 AND cvss_score <= 10.0),
    owasp_likelihood INTEGER CHECK (owasp_likelihood >= 1 AND owasp_likelihood <= 9),
    owasp_impact INTEGER CHECK (owasp_impact >= 1 AND owasp_impact <= 9),
    owasp_risk_rating VARCHAR(20),
    default_risk_rating VARCHAR(20),
    vulnerability_type VARCHAR(100),
    remediation_summary TEXT,
    remediation_steps TEXT,
    references TEXT,
    source VARCHAR(50) DEFAULT 'manual' NOT NULL,
    is_verified BOOLEAN DEFAULT FALSE NOT NULL,
    usage_count INTEGER DEFAULT 0 NOT NULL,
    created_at TIMESTAMPTZ,
    updated_at TIMESTAMPTZ,
    last_used TIMESTAMPTZ
);

CREATE INDEX ix_vulnerability_templates_title ON vulnerability_templates(title);
CREATE INDEX ix_vulnerability_templates_cwe_id ON vulnerability_templates(cwe_id);
CREATE INDEX ix_vulnerability_templates_cve_id ON vulnerability_templates(cve_id);
CREATE INDEX ix_vulnerability_templates_default_risk_rating ON vulnerability_templates(default_risk_rating);
```

### vulnerability_matches
```sql
CREATE TABLE vulnerability_matches (
    id SERIAL PRIMARY KEY,
    finding_id INTEGER NOT NULL REFERENCES finding(id),
    template_id INTEGER NOT NULL REFERENCES vulnerability_templates(id),
    similarity_score FLOAT NOT NULL CHECK (similarity_score >= 0.0 AND similarity_score <= 1.0),
    match_method VARCHAR(50) NOT NULL,
    matched_at TIMESTAMPTZ NOT NULL,
    matched_by VARCHAR(50) DEFAULT 'auto'
);

CREATE INDEX ix_vulnerability_matches_finding_id ON vulnerability_matches(finding_id);
CREATE INDEX ix_vulnerability_matches_template_id ON vulnerability_matches(template_id);
```

### finding (updated)
```sql
ALTER TABLE finding ADD COLUMN template_id INTEGER REFERENCES vulnerability_templates(id) ON DELETE SET NULL;
```

## 📊 API Examples

### Create Template
```bash
curl -X POST http://localhost:8000/vulnerability-templates \
  -H "Content-Type: application/json" \
  -d '{
    "title": "SQL Injection in Login Form",
    "description": "SQL injection allows attackers to execute arbitrary SQL",
    "cwe_id": "CWE-89",
    "cvss_vector": "CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H",
    "cvss_score": 9.8,
    "owasp_likelihood": 7,
    "owasp_impact": 9,
    "default_risk_rating": "Critical",
    "remediation_summary": "Use parameterized queries",
    "is_verified": true
  }'
```

### List with Filters
```bash
# Search for SQL-related templates
GET /vulnerability-templates?search=sql&risk_rating=Critical&is_verified=true

# Find all CWE-79 (XSS) templates
GET /vulnerability-templates?cwe_id=CWE-79

# Pagination
GET /vulnerability-templates?skip=10&limit=20
```

### Update Template
```bash
PATCH /vulnerability-templates/123
{
  "cvss_score": 8.5,
  "is_verified": true,
  "usage_count": 5
}
```

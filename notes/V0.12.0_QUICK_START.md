# v0.12.0 Quick Start Guide - Unified Template System

## 🚀 What's New?

Users can now **upload custom DOCX templates** and the platform fills them with real project data. Mix system templates and your own custom templates in any order!

---

## 📝 Creating a Custom Template

### 1. Create a DOCX file with Jinja2 placeholders

**Example: `executive_brief.docx`**

```
SECURITY ASSESSMENT BRIEF
{{ company_name }}

Project: {{ project.name }}
Date: {{ report_date }}
Period: {{ assessment_period }}

EXECUTIVE SUMMARY
Total Vulnerabilities: {{ findings|length }}

RISK BREAKDOWN
🔴 Critical: {{ risk_critical }}
🟠 High: {{ risk_high }}
🟡 Medium: {{ risk_medium }}
🟢 Low: {{ risk_low }}

TOP CRITICAL FINDINGS
{% for f in findings if f.risk_rating == "Critical" %}
{{ loop.index }}. {{ f.title }}
   CVSS: {{ f.cvss_score }}
   Impact: {{ f.description_text[:200] }}...
{% endfor %}

RECOMMENDED ACTIONS
{% for f in findings|sort(attribute='cvss_score', reverse=true)|slice(5) %}
- {{ f.title }}: {{ f.remediation_text[:150] }}...
{% endfor %}

Report prepared by {{ consultant_email }}
```

### 2. Upload via UI

1. Navigate to **Projects → [Your Project] → Reports → Modular Generator**
2. Click **"Upload"** button in Custom Templates section
3. Select your DOCX file
4. Fill in:
   - **Name**: "Executive Brief"
   - **Description**: "One-page executive summary"
   - **Public**: Check if you want to share with all projects
5. Click **"Upload"**

### 3. Use in Report

1. Select templates (mix system + custom):
   - ✅ Title Page (system)
   - ✅ Executive Brief (your custom template!)
   - ✅ Detailed Findings (system)
2. Fill in custom variables (company name, dates, etc.)
3. Click **"Generate Report"**
4. Download your customized DOCX report!

## 📚 Available Jinja2 Variables

### Most Used
| Variable | Example | Description |
|----------|---------|-------------|
| `{{ project.name }}` | "Web App Pentest" | Project name |
| `{{ findings\|length }}` | 42 | Total findings count |
| `{{ risk_critical }}` | 5 | Critical findings count |
| `{{ company_name }}` | "Acme Corp" | From form input |
| `{{ report_date }}` | "2025-11-12" | Report date |

### Finding Fields (in loop)
| Variable | Example | Description |
|----------|---------|-------------|
| `{{ f.title }}` | "SQL Injection" | Finding title |
| `{{ f.risk_rating }}` | "Critical" | Severity level |
| `{{ f.description_text }}` | "The app is vulnerable..." | Description (HTML stripped) |
| `{{ f.remediation_text }}` | "Implement parameterized queries..." | Fix instructions |
| `{{ f.cvss_score }}` | 9.8 | CVSS score |
| `{{ f.affected_components }}` | "/api/login, /api/users" | Affected areas |

### Jinja2 Tricks
```jinja2
{# Count high-severity #}
High+Critical: {{ findings|selectattr("risk_rating", "in", ["High", "Critical"])|list|length }}

{# Loop only critical #}
{% for f in findings if f.risk_rating == "Critical" %}
  ...
{% endfor %}

{# Sort by CVSS #}
{% for f in findings|sort(attribute='cvss_score', reverse=true) %}
  ...
{% endfor %}

{# Get top 5 #}
{% for f in findings|slice(5) %}
  ...
{% endfor %}

{# Conditional sections #}
{% if risk_critical > 0 %}
  ⚠️ URGENT: {{ risk_critical }} critical issues found!
{% endif %}
```

## 🔧 API Quick Reference

### List Templates
```bash
curl http://localhost:8000/projects/12/templates | jq .
```

### Upload Template
```bash
curl -X POST http://localhost:8000/projects/12/templates/upload \
  -F "file=@my_template.docx" \
  -F "name=My Template" \
  -F "description=Custom template for..." \
  -F "is_public=false"
```

### Generate Report
```bash
curl -X POST http://localhost:8000/projects/12/report/assemble/v2 \
  -H "Content-Type: application/json" \
  -d '{
    "template_ids": [5, 6, 17],
    "variables": {
      "company_name": "Acme Corp",
      "report_date": "2025-11-12",
      "assessment_period": "Q4 2024"
    }
  }' \
  --output report.docx
```

## 💡 Tips & Best Practices

### Template Design
- ✅ **Keep it simple**: Start with basic placeholders, add complexity later
- ✅ **Test with sample data**: Generate reports often while building template
- ✅ **Use conditionals**: Hide empty sections with `{% if %}`
- ✅ **Format dates**: Use `{{ report_date|default("YYYY-MM-DD") }}`
- ✅ **Truncate long text**: `{{ f.description_text[:200] }}...`

### Organization
- 📁 **System templates**: Official, well-tested templates (can't edit)
- 📁 **Public templates**: Shared across all projects (use sparingly)
- 📁 **Private templates**: Project-specific (most common)

### Performance
- ⚡ Use fewer templates for faster generation
- ⚡ Keep custom variables simple (strings, numbers, dates)
- ⚡ Avoid deeply nested loops in templates

## 🐛 Troubleshooting

### Template Not Showing Up
- **Check**: Did upload succeed? Look for success message
- **Fix**: Refresh page or click "Refresh" button

### Placeholders Not Filled
- **Check**: Spelling matches exactly (case-sensitive!)
- **Fix**: Use `{{ variable|default("fallback") }}` for optional fields

### Report Generation Fails
- **Check**: All selected templates exist (green checkmark)
- **Fix**: Deselect missing templates and try again

### Permission Errors
```bash
# If uploads fail with permission errors:
docker exec -u root vuln-manager-backend-1 \
  chown -R appuser:appuser /code/storage/templates/
```

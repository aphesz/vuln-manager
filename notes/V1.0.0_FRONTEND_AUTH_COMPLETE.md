## 🔐 Authentication Flow

### 1. Initial Load
```
App loads → AuthProvider initializes
  ↓
Check localStorage for access_token & user
  ↓
If found → Validate with GET /auth/me
  ├─ Valid → Set user state, allow access
  └─ Invalid → Clear localStorage, redirect to /login
  ↓
If not found → user = null, redirect to /login
```

### 2. Login Flow
```
User visits /login (public route)
  ↓
Enter email + password → Submit form
  ↓
POST /auth/login (OAuth2 password flow)
  ↓
Backend validates → Returns tokens + user object
  ↓
Store in localStorage:
  - access_token
  - refresh_token
  - user (JSON)
  ↓
Set user state → Redirect to intended page (or /)
```

### 3. Token Refresh Flow
```
API request → 401 Unauthorized
  ↓
Interceptor catches 401
  ↓
POST /auth/refresh with refresh_token
  ↓
Backend returns new access_token
  ↓
Store new access_token → Retry original request
  ↓
If refresh fails → Logout → Redirect to /login
```

### 4. Logout Flow
```
User clicks Logout in UserMenu
  ↓
Call logout() function
  ↓
POST /auth/logout (optional, for logging)
  ↓
Clear localStorage (tokens + user)
  ↓
Set user state to null
  ↓
Redirect to /login
```

## 🔧 Technical Implementation

### State Management
- **Global Auth State**: React Context API
- **Local Component State**: useState hooks
- **Loading States**: Boolean flags for async operations
- **Error States**: String | null for error messages

### API Communication
- **Base URL**: http://localhost:8000
- **Axios Instance**: Custom instance with interceptors
- **Headers**: Automatic `Authorization: Bearer <token>`
- **Error Handling**: Try/catch with user-friendly messages
- **Token Refresh**: Automatic on 401 responses

### localStorage Keys
- `access_token`: JWT access token (30 min)
- `refresh_token`: JWT refresh token (7 days)
- `user`: JSON-stringified user object

### Type Safety
- TypeScript interfaces for User, LoginResponse, AuthContext
- Proper typing for all functions and props
- No `any` types in production code (only error handling)

## 🐛 Known Issues / Considerations

### 1. CORS Configuration
- **Current**: Backend allows all origins (`allow_origins=["*"]`)
- **Production**: Should restrict to frontend domain only
- **Fix**: Update `backend/app/main.py` CORS middleware

### 2. Token Storage
- **Current**: Tokens in localStorage (vulnerable to XSS)
- **Improvement**: Use httpOnly cookies for refresh tokens
- **Security**: Ensure HTTPS in production

### 3. Token Expiration
- **Current**: Access token expires in 30 minutes
- **Refresh**: Automatic via interceptor
- **Session**: Refresh token expires in 7 days (force re-login)

### 4. Password Reset
- **Missing**: No password reset flow

- **Backend**: Need reset token endpoint + email service

## 📚 Developer Guide

### Adding a New Protected Page

1. **Create Component**
```tsx
// frontend/src/components/MyNewPage.tsx
import { useAuth } from '../contexts/AuthContext';

const MyNewPage: React.FC = () => {
  const { user, hasRole } = useAuth();
  
  return (
    <Container>
      <PageBreadcrumbs items={[...]} />
      <Typography variant="h4">My New Page</Typography>
      {/* Your content */}
    </Container>
  );
};
```

2. **Add Route**
```tsx
// frontend/src/App.tsx
<Route path="/my-page" element={
  <ProtectedRoute requiredRoles={['admin', 'analyst']}>
    <MyNewPage />
  </ProtectedRoute>
} />
```

3. **Add to Sidebar Navigation**
```tsx
// frontend/src/components/Sidebar.tsx
{
  label: 'My Page',
  path: '/my-page',
  icon: <MyIcon />,
}
```

### Making Authenticated API Calls

```tsx
import { api } from '../contexts/AuthContext';

// GET request
const response = await api.get('/projects');
const projects = response.data;

// POST request
const response = await api.post('/projects', {
  name: 'New Project',
  description: 'Description',
});

// Token automatically attached in Authorization header
// Auto-refresh on 401 errors
```

### Checking User Permissions

```tsx
import { useAuth } from '../contexts/AuthContext';

const MyComponent = () => {
  const { user, hasRole } = useAuth();
  
  // Check if user is authenticated
  if (!user) return <div>Not logged in</div>;
  
  // Check specific role
  if (hasRole('admin')) {
    return <AdminPanel />;
  }
  
  // Check multiple roles
  if (hasRole('admin', 'analyst')) {
    return <AnalystPanel />;
  }
  
  return <ViewerPanel />;
};
```

## 🎓 Key Learnings

1. **Context API**: Perfect for global auth state (avoid prop drilling)
2. **Axios Interceptors**: Clean way to handle auth headers and token refresh
3. **localStorage**: Simple token storage, but consider security trade-offs
4. **ProtectedRoute Pattern**: HOC makes route protection declarative
5. **Loading States**: Essential for good UX during async operations
6. **Error Handling**: Always show user-friendly messages, not technical errors
7. **Role-Based UI**: Hide/show features based on user permissions
